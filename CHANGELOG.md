# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.4] - 2026-06-13

### Fixed

- `changelog_changeset/1` now declares `unique_constraint(:id, name: "<table>_pkey")` so that duplicate pkey violations on the audit log (e.g. sequence rewind inside a tx) produce a changeset error instead of escaping as `Ecto.ConstraintError`. Closes OPS-4600.

## [1.0.3] - 2026-05-28

### Fixed

- `*_and_log/*` and `log/*` no longer raise a `:rollback` `RuntimeError` when called from inside an `Ecto.Multi`. Closes OPS-3479.

## [1.0.2] - 2025-04-07
